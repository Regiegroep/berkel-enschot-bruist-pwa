# Berkel-Enschot Bruist PWA
## Productlog

Dit document beschrijft de ontwikkeling van de PWA vanuit functioneel perspectief.

Het is nadrukkelijk geen technische changelog.

Per versie wordt vastgelegd:

- doel van de release;
- belangrijkste wijzigingen;
- genomen besluiten;
- openstaande punten voor de volgende versie.

---

# v0.6

## Doel

Werkende basisversie van de PWA.

## Opgeleverd

- Google Sheets koppeling
- Programmaoverzicht
- Zoeken
- Filters
- Detailpagina
- Responsive layout
- Homepage definitief ontwerp

## Bekende beperkingen

- Mijn Bruist nog niet actief
- Plattegrond nog niet actief
- Offline nog niet actief
- Tags nog niet gebruikt
- Publicatiestatus nog niet toegepast

## Besluit

Programmakern vormt de stabiele basis voor verdere ontwikkeling.
